## Project Overview & Research Aim

This repository contains the complete experimental setup, stimulus delivery platform, raw participant log datasets, and statistical analysis pipeline for the empirical study on human capability to detect AI-generated avatars under viewing time constraints.

### Key Research Questions
* **RQ1:** Does limiting viewing exposure time to **3 seconds** significantly decrease human detection accuracy ($Acc$) compared to unrestricted viewing time?
* **RQ2:** Does time scarcity cause an asymmetrical increase in **False Positive Rate ($FPR$)** (mistaking AI avatars for real humans) over **False Negative Rate ($FNR$)**?

## 🚀 Quickstart & Reproducibility Guide

Все скрипты определяют корень проекта сами, поэтому их можно запускать из любой папки.
Нужен Python 3.11+ (работает и на более новых версиях).

### Option 1: Native Python Environment

```bash
# 1. Clone the repository
git clone https://github.com/DIMASUBMARINA/ai-avatar-perception-study.git
cd ai-avatar-perception-study

# 2. Create and activate a virtual environment
python -m venv .venv
# On Windows:
.venv\Scripts\activate
# On macOS/Linux:
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the complete pipeline (in this order)
python src/benchmark.py      # -> data/raw/test_run.jsonl, data/processed/metrics_summary.json
python src/process_data.py   # -> data/processed/metrics_summary.csv
python src/visualize.py      # -> reports/figures/*.pdf, *.png

# 5. (Optional) Run the tests
python -m pytest -q
```

### Option 2: Conda Environment

```bash
conda env create -f environment.yml
conda activate avatar-perception
python src/benchmark.py && python src/process_data.py && python src/visualize.py
```

### Option 3: Docker Container

```bash
docker build -t avatar-perception .
docker run --rm avatar-perception
```

> Результаты остаются внутри контейнера. Чтобы получить файлы на хосте, смонтируйте папки:
> `docker run --rm -v "$(pwd)/data:/app/data" -v "$(pwd)/reports:/app/reports" avatar-perception`
