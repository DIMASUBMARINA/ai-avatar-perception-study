## Project Overview & Research Aim

This repository contains the complete experimental setup, stimulus delivery platform, raw participant log datasets, and statistical analysis pipeline for the empirical study on human capability to detect AI-generated avatars under viewing time constraints.

### Key Research Questions
* **RQ1:** Does limiting viewing exposure time to **3 seconds** significantly decrease human detection accuracy ($Acc$) compared to unrestricted viewing time?
* **RQ2:** Does time scarcity cause an asymmetrical increase in **False Positive Rate ($FPR$)** (mistaking AI avatars for real humans) over **False Negative Rate ($FNR$)**?

## Quickstart & Reproducibility Guide

Follow these 3 simple commands to reproduce the data processing and statistical analysis from scratch:

